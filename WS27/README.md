## Was sich gegenüber dem ersten Versuch ändert

| SS26 (nicht bestanden) | WS27 |
|---|---|
| 9 Aufgabentypen aus alten Klausuren, Rest gestrichen | **komplette offizielle Themen-Auswahl** |
| vorsortierte Drills (Thema stand in der Überschrift) | **Erkennung zuerst**: gemischte Aufgaben, klassifizieren, dann rechnen |
| alte Klausuren als Maßstab | **Übungsaufgaben des Skripts als Aufgabenpool** (die Juli-Klausur bestand aus Varianten davon) |
| Formeln einsetzen | Verteilungen **selbst aufstellen**, E und Var aus der Definition |
| Probierformel, Rückwärtseinsetzen | **Euklid-Tableau**, Faktorisieren bis √n, Probe nach jedem Schritt |
| Spicker mit Formeln | Spicker mit **Entscheidungshilfe** + erklärte Fassung |
