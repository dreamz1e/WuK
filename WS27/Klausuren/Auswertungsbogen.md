## Maßnahmen nach Fehlercode

| Code | Bedeutung | Konsequenz (bis zur nächsten Probeklausur erledigen) |
|---|---|---|
| **E** | nicht erkannt | Signalwörter der Aufgabe in Spicker-Abschnitt ⓪ ergänzen · 5 Aufgaben Erkennungstraining · dieselbe Aufgabe in 3 Tagen noch einmal nur **klassifizieren** |
| **A** | falscher Ansatz | Abschnitt im Themen-Modul lesen, Herleitung 1× selbst aufschreiben, 2 Aufgaben desselben Typs |
| **R** | verrechnet | Aufgabe sofort noch einmal sauber rechnen; Zwischenergebnisse künftig untereinander schreiben und mit dem TR gegenprüfen |
| **P** | Probe ausgelassen | Probe-Ritual auf den Spicker (Σ P = 1 · a·x + b·y = ggT · e·d mod φ = 1 · mᵉ mod n = c · n−1 und n bei Ungleichungen) |
| **Z** | Zeitproblem | Reihenfolge prüfen (Sicherstes zuerst?), 3-Minuten-Abbruchregel, Tempo-Drill des langsamsten Typs mit Stoppuhr |
| **W** | Wissenslücke | Thema im Lernplan nachtragen — **nichts aus der offiziellen Themen-Auswahl streichen** |
